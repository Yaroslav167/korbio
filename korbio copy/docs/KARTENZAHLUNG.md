# Keine Kartendatei erforderlich

Die private Korbio-Familienkasse verbindet weder Zahlungskarte noch Bankkonto. Familienbeiträge können bar an den Familienadmin gegeben werden. Eine normale Überweisung an eine bei der Einrichtung optional hinterlegte IBAN bleibt möglich.

Kartennummer, Ablaufdatum, CVC, PIN und Online-Banking-Passwort dürfen niemals in `.env`, den Quellcode, eine Katalogdatei oder ein Support-Formular eingetragen werden. Für den reinen Barbetrieb benötigt Korbio keine Bankdaten.

Soll später eine echte Karten- oder Apple-Pay-Zahlung für fremde Nutzer hinzukommen, muss das über einen dafür geeigneten, vertraglich freigegebenen Zahlungsdienstleister mit dessen gehosteter Zahlungsseite erfolgen. Eine solche öffentliche Zahlungsfunktion ist nicht Bestandteil dieser Familienversion.
